Today I worked on live bug bounty testing (Intigriti target) focusing on XSS discovery.

- Input reflected behavior was limited or removed
- Shifted focus to observing request flow and DOM behavior instead of payload testing

Key learning:
Real-world XSS hunting is more about understanding how input flows through an application than directly trying payloads.
